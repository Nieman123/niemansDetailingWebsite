# Nieman's Detailing Website

Production website for Nieman's Detailing, a mobile car detailing business serving Asheville, NC and the surrounding area.

This repo contains:

- A static marketing site served from Firebase Hosting
- A Firebase Functions backend for lead capture and quote progress events
- A local image pipeline that generates responsive AVIF/WebP/JPG variants
- A static blog build script
- Lighthouse CI config and homepage performance-focused frontend work

## Stack

- Frontend: hand-authored HTML, CSS, and vanilla JavaScript in `public/`
- Hosting: Firebase Hosting
- Backend/API: Firebase Functions v2 + Firestore
- Tooling: Node.js scripts, Sharp, Cheerio, fast-glob, Lighthouse CI

## Repo Layout

- `public/`
  Deploy root for Firebase Hosting. Contains the homepage, static pages, blog output, admin pages, scripts, styles, fragments, and generated images.
- `public/fragments/`
  Lazy-loaded homepage tab content such as Services, About, and Contact.
- `public/styles/`
  Site CSS, including homepage-specific styles and critical CSS.
- `public/scripts/`
  Frontend JavaScript for the homepage, blog, admin, and shared behavior.
- `public/images/`
  Generated and synced public image assets used by the site.
- `assets/images/`
  Source-of-truth image originals. These are copied and transformed into `public/images/`.
- `functions/`
  Firebase Functions source. The current API handles lead creation and quote progress tracking.
- `scripts/`
  Build and maintenance scripts for the blog, image rewiring, and emulator seeding.
- `tools/`
  Image processing utilities, including the responsive image build script.
- `firebase.json`
  Hosting, headers, rewrites, emulator config, and predeploy hooks.
- `lighthouserc.json`
  Lighthouse CI configuration for performance checks.

## Local Development

Install dependencies in the repo root:

```bash
npm install
```

Run the site locally:

```bash
npm run dev
```

That command:

- syncs source images from `assets/images/` into `public/images/`
- builds responsive image variants
- rewires HTML image markup to use responsive assets
- serves `public/` locally on port `5173`

Useful commands:

```bash
npm run images:sync
npm run build:blog
npm run lhci
```

For Functions development/build:

```bash
cd functions
npm install
npm run build
```

## Deployment Notes

- Firebase Hosting serves directly from `public/`
- `npm run images:sync` runs automatically as a Firebase Hosting predeploy step
- HTML is short-lived in cache; images are long-lived and immutable
- Route rewrites in `firebase.json` map friendly URLs like `/schedule`, `/quote`, and `/blog`
- `/api/**` is handled by the Firebase Function exported from `functions/index.ts`

## Content and Asset Workflow

- Add or replace original images in `assets/images/`
- Run `npm run images:sync`
- Commit both source updates and generated public assets when needed
- Blog pages are statically generated by `scripts/build-blog.mjs`
- Homepage content is partially split into fragment files for lazy hydration and better mobile performance

## Color Palette

The site should stay on a dark detailing-oriented palette and avoid pale lavender card backgrounds.

### Core colors

| Token | Value | Use |
| --- | --- | --- |
| `--nd-bg-0` | `#02050D` | Deepest page background |
| `--nd-bg-1` | `#08112A` | Primary page gradient |
| `--nd-bg-2` | `#040814` | Lower page gradient / depth |
| `--nd-surface` | `#0F1832` | Base dark surface |
| `--nd-surface-elevated` | `#162142` | Raised panels and overlays |
| `--nd-surface-strong` | `#0B1228` | Strongest dark surface |
| `--nd-accent-0` | `#341F67` | Plum anchor for nav/CTA gradients |
| `--nd-accent-1` | `#5534A8` | Primary purple accent |
| `--nd-accent-2` | `#BBA6FF` | Text accent / headings / links |
| `--nd-highlight-0` | `#F09D2C` | Pricing / money highlight start |
| `--nd-highlight-1` | `#DA6B1F` | Pricing / money highlight end |
| `--nd-text-on-dark` | `#F2F0FF` | Main text on page background |
| `--nd-text-on-surface` | `#F4F1FF` | Main text on cards and panels |
| `--nd-text-muted` | `#C8C2DB` | Secondary text on dark surfaces |
| `--nd-text-subtle` | `#A7A2BC` | Low-emphasis helper text |

### Usage rules

- Backgrounds should stay in the `--nd-bg-*` range with deep navy/ink gradients
- Cards, panels, chips, and overlays should use dark translucent surfaces, not pale glass panels
- Purple is the primary accent for navigation, active states, and CTAs
- Amber is reserved for pricing and monetary cues
- Use `--nd-text-on-surface` or `--nd-text-muted` on dark surfaces; avoid dark text inside cards

### Current implementation

The homepage palette tokens and dark surface treatments currently live in `public/styles/home.css`.
